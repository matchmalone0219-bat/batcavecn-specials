# Batman小站 · Protocol Arkham 与 Dark Deco 专题档案

Batman小站专题档案项目：一个仓库、两个独立专题。两站共享静态生成器、部分资料数据与凯文·康罗伊人物档案，但保持各自的视觉、导航与搜索边界。

- **Protocol Arkham / 阿卡姆协议**：以游戏启动界面、终端菜单与哥谭档案馆为核心。
- **Dark Deco / TAS 动画档案**：以动画放映室、节目单、制作画册与档案阅读为核心。
- 当前尚未部署正式域名或子域；仓库中的 `dist/` 为本地生成产物，不提交。

## 当前状态

### Protocol Arkham

- 首页使用约一分钟的《阿卡姆之城》标题画面剪辑：1920×1080、30fps、59.93秒、约18.09MiB，静音循环。
- 295秒完整配乐独立为约4.55MiB M4A，默认不加载；点击“开启配乐”后才请求并播放。
- 点击“激活协议 / ACTIVATE PROTOCOL”或按 Enter，以蝙蝠群动画和独立转场音效进入七项主菜单。
- 主菜单使用六部作品各一张真实游戏截图全幅轮播，覆盖《疯人院》《之城》《起源》《黑门》《骑士》《自杀小队》；作品档案、哥谭档案馆、蝙蝠侠之声、周边档案、图片资料、搜索档案、资料来源彼此独立。
- 六部游戏均有详情页，包括《阿卡姆起源：黑门》与《自杀小队：消灭正义联盟》；哥谭档案馆现有谜语人考据、场景物件、哥谭故事、漫画与出版、疯人院院史、患者访谈，以及十三节 Rocksteady 创作变迁档案。
- 阿卡姆站内不混入 TAS 导航；凯文·康罗伊使用阿卡姆专属阅读视图与回链。

### Dark Deco

- BTAS 85条基础目录与 TNBA 24条基础目录分开编目。
- 现有17篇 BTAS 深度分集档案，包含剧情简介、人物关系、主题解读、声音制作、图片资料与折叠结局。
- TAS 档案馆包含制作与美术、角色与声音、动画电影、《幽灵的面具》、漫画与出版、配乐、创作与延续等页面。
- 《披风斗士》作为现代再诠释独立编目，两季共20集英文节目单。
- 首页与长文页面使用 Dark Deco 的放映室／纸质节目单视觉，专题字体为思源黑体 ExtraLight。

### 共同资料

- 凯文·康罗伊人物档案由两站共享数据；共同页保留两边作品回链。
- 两站都有来源页、图片资料页、周边档案与搜索。
- 当前共 **57个页面、475条可搜索记录**。
- 剧透内容默认折叠，搜索索引不包含结局正文。

## 启动与编辑

需要 Python 3.10+，无需第三方依赖。

```sh
python3 serve.py
```

打开 `http://127.0.0.1:8765/`。

本地编辑器通过页脚“编辑文案”进入，仅监听本机。它可以修改 `archive.json` 中已开放的标题、导言和正文字段；保存前检查版本冲突，保存时自动备份并重新生成静态页。研究 JSON、来源元数据、新条目与媒体资料仍直接维护对应结构化文件。

python3 build.py

node verify-intro.js

## 代码结构

- `build.py`：读取、校验并输出页面、搜索索引与资产。
- `site_pages.py`：组合全站路由与搜索记录。
- `site_layout.py`：两专题导航、样式、脚本与搜索范围。
- `render_common.py`：共用转义、资料片段、作品路由与人物链接。
- `content_pages.py`：首页、作品详情、披风斗士与人物页。
- `arkham_ui.py`：Protocol Arkham 启动画面、菜单与游戏目录。
- `rocksteady-history.json`：2009—2026年工作室、设计与发行后变化，区分日期事件、采访转述和作品分析。
- `tas_pages.py` / `arkham_pages.py`：两边研究档案页面。
- `style.css`：公共结构；`arkham.css` 与 `tas.css` 分别维护专题视觉。
- `build_assets.py`：按实际字节比较并复制变化资产。

更完整的模块说明见 [CODE-STRUCTURE.md](CODE-STRUCTURE.md)。

## 内容与资料规则

前台文案遵循 [CONTENT_GUIDE.md](CONTENT_GUIDE.md)：页面直接介绍作品、人物与创作，不展示内部核验流程、补证任务或防御性说明。来源性质、译名、版本差异、连续性差异、剧透提示等对读者有意义的信息保留。

结构化资料遵循以下原则：

- 指南编号、制作代码、首播地区、影音顺序等字段分别维护，缺失内容不互相推算。
- 游戏原作、移植、合集、DLC 与商业版本分开记录。
- BTAS、TNBA、《披风斗士》及其他连续性不混写。
- 社区资料、攻略、玩家转录与官方资料保持来源层级区别。
- 图片保留原比例、出处、版本与校验值；不去水印、不拉伸。

研究口径与缺口见 [RESEARCH.md](RESEARCH.md)、[RIDDLER.md](RIDDLER.md)、[ARKHAM-ARCHIVE.md](ARKHAM-ARCHIVE.md)、[TAS-RESEARCH.md](TAS-RESEARCH.md)、[TAS-PRODUCTION.md](TAS-PRODUCTION.md)、[MEDIA.md](MEDIA.md)。
