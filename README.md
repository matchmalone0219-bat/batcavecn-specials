## 启动与编辑

需要 Python 3.10+，无需安装第三方依赖。在仓库根目录：

```sh
python3 serve.py
```

打开 http://127.0.0.1:8765/ ，通过页脚“编辑文案”选择页面、文字字段并保存。文本预览即时更新，实际保存会写入 archive.json，自动备份到 backups/，然后重新生成静态页。保存后刷新预览页。

编辑器仅监听本机；不是线上管理后台，保存也不会自动推送到GitHub。事实元数据、来源和新条目由结构化内容文件维护，界面首轮只编辑标题、导言、正文与资料边界。页面样式在 style.css 中独立维护。多人窗口修改有版本冲突检查，未保存切换有提醒。

## 生成与检查

```sh
python3 build.py
python3 verify.py
node --check app.js
```

输出为 dist/。网站根目录预览支持 /arkham/、/tas/、/people/kevin-conroy/；不是双击HTML的file预览，也尚未配置GitHub Pages项目子路径。线上部署时应排除 /editor/ 与本地编辑服务，分别确定子域路由和唯一共享人物档案地址后再发布。

## 内容依据与视觉

41条来源记录含DC官方游戏资料、康罗伊本人访谈、官方回顾与纪念，以及The World’s Finest分集辅助索引。各页面显示核查日期与事实缺口；中文分集名标本站暂译。指南编号、原始制作代码、首播地区与影音顺序独立存储，缺资料不互相推算。剧情默认折叠，搜索索引不包含剧透正文。
