# 谜语人同框目标对照 · 2026-10-26

用户批准扫描成功后，在原现场图片框中用0.25秒淡入目标特写，下方只保留解法；提供“现场｜扫描目标”按钮切换，再点图片收起并恢复现场。本批未增加滚动跳转、放大查看或上一题／下一题。

## 实施

- `arkham_riddler.py`给原生目标图增加专用钩子。无脚本时，目标图仍在原生谜底折叠内。
- `arkham-riddler-scan.js`只在增强后的当前详情中移走重复目标图；扫描后在原框显示目标，图注、原图链接和按钮状态随当前视图切换。比较按钮使用原生button，支持Enter／空格，隐藏时不可操作。
- `arkham-riddler-scan.css`用现场图原始比例固定图片框，目标图完整contain显示，两个图层以250毫秒透明度过渡。目标显示时淡去模拟成功横幅，保留截图自身的游戏文字和水印。减少动态效果关闭过渡。
- 目标加载慢时先显示现场与文字解法，载入后再切换；失败时保留现场并禁用目标按钮，后续扫描可重试。收起、切题后，旧目标的延迟加载不再揭示下一题。
- 扫描前不挂载增强目标图层、不显示对照入口。浏览器原有cloneNode流程可能预读原生折叠内的目标图片，本批不以“扫描前零目标图请求”为验收声明。原图文件和音效均未改写。
