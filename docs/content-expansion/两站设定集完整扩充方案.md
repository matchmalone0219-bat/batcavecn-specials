# 两站设定集图文扩充方案

日期：2026-10-23。范围：Protocol Arkham 与 Dark Deco 两个既有专题站。本文是可执行的编辑方案，本轮没有继续写入设定集正文或新增站点图片。

## 一、建议采用的规模与方向

两本书正好分别补强两个站点。第一批建议完成 **20个主体图文章节（阿卡姆8个、动画12个）、59幅精选图（24＋35）、15个TAS角色头像，以及12篇现有分集的制作补充**。文字总量目标约1.2万—1.8万中文字，包含主体与分集短节；按材料密度调整，不为凑数量拆段或配图。

59是选图预算，不是全书可用图片总量，也不是已完成数量。15个角色头像优先从同批模型纸／角色图另制小图；分集优先复用上述图片资源。若15人中的合适模型纸不在59幅选择内，允许替换图选或增加少量专用裁切，交付时报告实际独立文件数。

内容进入已有作品页、档案馆六个分区、电影页和分集页，第一批不新增顶层栏目。图片资料页作为同一素材的浏览入口，正文保留完整论述；同一篇文章不在多个栏目重复出现。

## 八、图片与页面怎么呈现

### 选图与文字

- 以原创中文概括和具体图像分析为正文。一个图片组解决一个问题，例如“草图到最终模型”“两代造型”“同一空间的前后状态”。不整本翻译，也不把整页扫描缩成难读的小图。
- 正文图片不加图名、图注、来源链接、版权警告或自证文案。普通章节标题和介绍要讲设计内容。准确的画师、图像类型、源文件、裁切框和书目在素材元数据及独立来源页维护。
- 保留有意义的概念稿／未采用方案／BTAS／TNBA版本区别；以段落内容或组别表达，避免读者把探索图当成成品。
- 原文件保持原样。网页图片只做裁切、必要的旋转和压缩，不用生成式工具补线稿、重绘角色或补出原图之外的内容。

### 页面布局

- 完成度高的单幅背景与场景图可横向展示；模型纸和前后对照采用两列，手机堆叠。分镜按阅读顺序形成2—4个镜头组，避免缩成一排难以辨识的邮票。
- 沿用两站现有风格：游戏站的档案界面、动画站的放映室。卡片整张可点；不添加左边框色条或左侧竖线。
- 角色名册增加小头像和必要的角色设计摘要；录音终端使用既有新增配图，不在此轮再更换播放器风格。
- 图库只增加“角色／环境／装备／分镜”分组或简洁筛选；复用正文资源与现有灯箱。TAS灯箱继续无图名，提供原图查看和翻页。
- 首页只从新增内容中替换／补充现有制作图册推荐位的两张选页；不改站点主视觉，不新加多个重复入口。

### 图像规格与加载

主体图一般长边1400—1800像素，模型纸保留可读细节；头像统一比例，另输出小尺寸缩略图。使用现有支持的JPEG／PNG，线稿避免过度压缩；按实际照片质量决定是否保留PNG。内部保存高分辨率选区，网页使用适配尺寸。

除首屏必要图片外延迟加载，明确宽高，避免页面跳动；正文、图库与角色列表复用资源。若图量导致长页明显变重，先采用已有折叠与分组，必要时再讨论拆出详情页。

## 九、来源、事实与连续性的处理
